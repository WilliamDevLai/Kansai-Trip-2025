# Kansai-Trip-2025
🇯🇵 京阪神 6 日旅行儀表板 (Kansai Travel Dashboard)

這是一個為 12/20 至 12/25 的京阪神之旅設計的行動響應式網頁應用程式。

🌐 部署狀態 (GitHub Pages)

您可以點擊以下連結查看已部署的網站：
[旅行儀表板連結](在此插入您的 GitHub Pages 網址)
請在部署完成後，將上方的文字替換為實際的網址。

🛠️ 核心功能

每日行程卡片： 清晰劃分景點、美食、交通與住宿。

導航整合： 景點設有「導航」按鈕，方便自駕或查詢路線。

導遊提示 (Gemini API)： 提供每日景點的深度攻略、必吃美食、必買伴手禮。

實用工具： 包含航班、住宿、緊急聯絡電話與本地記帳功能。

📜 如何部署 (Deploy Instructions)

請將您的 index.html 檔案上傳到您的 GitHub 儲存庫的根目錄，並按照以下步驟啟用 GitHub Pages：

進入您的 GitHub 儲存庫頁面。

點擊上方的 Settings (設定)。

在左側選單中，點擊 Pages (頁面)。

在 Build and deployment 下的 Source (來源) 選項中，選擇 main 分支（或您使用的分支）。

確認資料夾設定為根目錄 /。

點擊 Save (儲存)。

幾分鐘後，GitHub Pages 會自動部署您的網頁，並提供一個公開網址。
